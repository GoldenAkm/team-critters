# Who's working on what

Check this before you start editing so two people don't change the same file at once.

## How to use it

1. `git pull` first.
2. Make sure nobody else has the file or folder you want.
3. Add it under your name, then commit and push this file straight away.
4. Only edit your own section.
5. When you're done, push your work and clear your section.

Need a file someone else has? Message them first.
Shared files (`critters_context.md`, `CLAUDE.md`): say so in the group chat before editing.
